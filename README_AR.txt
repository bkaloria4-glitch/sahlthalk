منصة سهلتهالك بكالوريا - نسخة Render التجريبية

الملفات:
- app.py: تطبيق Flask
- requirements.txt: المكتبات اللازمة
- render.yaml: إعدادات النشر المقترحة

النشر:
1) ارفع محتويات هذا المجلد إلى مستودع GitHub.
2) في Render اختر New + ثم Blueprint، واربط المستودع.
3) راجع متغيرات البيئة واضغط Apply.
4) سجّل الدخول إلى لوحة الإدارة باسم المستخدم admin وكلمة المرور التي تم توليدها في Render ضمن Environment.
5) بعد الدخول غيّر كلمة مرور الأدمن من لوحة الإدارة فورًا.

تنبيه مهم للبيانات:
هذه النسخة تستخدم SQLite محليًا. نظام ملفات خدمة Render المجانية مؤقت، لذلك لا تستخدمها مع طلاب حقيقيين أو مدفوعات فعلية قبل نقل قاعدة البيانات إلى PostgreSQL دائم أو إعداد تخزين دائم مناسب. لا تضع بيانات دفع حقيقية في نسخة تجريبية.

الوظائف المتاحة للأدمن:
- إضافة وتعديل أسعار وأوصاف الكورسات وإظهارها أو إخفاؤها.
- إضافة الأسئلة وحذفها.
- مراجعة طلبات فودافون كاش وقبولها/رفضها وتفعيل الاشتراك.
- مشاهدة الطلاب واشتراكاتهم وإلغاء اشتراك.
- مشاهدة آخر نتائج الاختبارات.
- تعديل رقم فودافون كاش الظاهر للطلاب.
- تغيير كلمة مرور الأدمن.
